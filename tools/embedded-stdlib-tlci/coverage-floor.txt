# Native-coverage ratchet for the embedded stdlib tlci image.
#
# scripts/verify-embedded-stdlib-tlci.sh reads these bounds and fails when the
# image built from the checked-in stdlib sources drops below the floor. Nothing
# else pins the coverage numbers, so without this file a producer change can
# silently move macros back onto the interpreted route and only a compile-time
# profile row would notice.
#
# native-entries-min   entries whose transformer body compiles to a native
#                      entry function rather than a registration shell.
# shell-entries-max    entries that only register an interpreted fallback.
# partial-entries-max  native entries containing an interpreted arm.
# interpreted-arms-max individual arm sites that return ok-with-no-result.
#
# These are a ratchet, not a target: raise the floor and lower the ceiling as
# families land, never the other way around.
#
# Improving past the ratchet is not a failure -- macro families land
# concurrently and an exact expectation would collide on every merge -- but the
# verify script prints the numbers to paste here, and re-ratcheting is part of
# each family's acceptance criteria.
#
# Every checked-in entry is fully native, so every fallback dimension is pinned
# to zero rather than allowing a future catalog addition to hide one.
# 164 since #8449: `stdlib.string/string-bytes-copy!` was removed with its
# only expansions, `str-copy-owned-bytes-into` and `str-copy-borrowed-bytes-into`,
# safe functions that wrote through a caller's raw `MutPtr` (an unchecked
# write from a safe signature); no other source expands it.
native-entries-min 164
shell-entries-max 0
partial-entries-max 0
interpreted-arms-max 0
